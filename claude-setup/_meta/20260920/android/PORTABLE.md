# 便携包使用边界

这是当前工作区导出的 Skills + Rules 轻量包。原项目文件未被修改。

- 用途、路由、证据纪律及所附 references/assets 保留；本机设备标识替换为占位符。
- 文中“本机”“已安装”“只连某端口”“无 ObjC bridge”、工具数和历史通过结果均是原项目环境记录，不代表你的电脑或设备状态。使用前按当前任务核实。
- 本包没有 MCP 程序/配置、ADB/JADX/IDA/Frida 二进制、Python 环境、SSH 密钥、登录凭据、业务脚本、抓包和样本。对应能力需另行安装和配置；不要把缺失工具描述成已可用。
- 仅修改 .claude/skills 真源，再同步当前平台镜像和相关 Rules。不要把两套内容合并到一个项目根或用户全局 Skills。
- 原设备和账号授权不会随 ZIP 转移。依当前用户已给定的任务范围执行；未配置目标时不进行设备动作。
- 包内初始化脚本只生成当前项目 Skills 镜像/联接及协议薄 Rule，不改 MCP、IDE 用户全局配置、账号或设备。
- 历史记忆只提供明确标记的入口说明，不补造证据；本包不包含原工作区历史记忆正文。只在用户明确要求时更新当前项目记忆。
- 新电脑应打开包含 CLAUDE.md、AGENTS.md 和 .claude 的平台项目根；不要只打开 tools 或 .claude 子目录。

具体外部依赖见 EXTERNAL_DEPENDENCIES.md。原始版本来源、源 SHA-256 和便携变换见外层 PACKAGE_MANIFEST.json、PORTABILITY_CHANGES.json。
