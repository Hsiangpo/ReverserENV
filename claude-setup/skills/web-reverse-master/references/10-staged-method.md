# 分阶段路线、计划、执行与排错

只在任务需要对应阶段时读取相关章节。这里统一保存路线设计、计划、执行、样本驱动复现与证据链排错方法；通用 Phase 细节仍见 `01-workflow.md`。

## 1. 按现场选入口

| 当前状态 | 进入章节 |
|---|---|
| 不知道从哪层开始或有多条路线 | 路线设计 |
| 路线已定，需要可执行方案 | 实施计划 |
| 已有用户确认的计划 | 按计划执行 |
| 正在复现 sign/encrypt/decrypt/protocol | 样本驱动复现 |
| 输出不一致、Hook 无效或结果漂移 | 证据链排错 |
| 缺口明确为验证码/已知加密/补环境/AST | 直接调用专业 Skill |

## 2. 路线设计

先写一句可验证目标，再收集已有事实、样本、工具条件和不可触碰边界。只列能区分关键假设的 2–4 条路线，每条写明：

- 能回答哪个问题；
- 所需输入与工具；
- 预期证据；
- 成本、风险和停止条件；
- 失败后转向哪里。

优先选择能直接闭合当前缺口且成本最低的路线，不做“静态→Hook→模拟→真实浏览器”逐级通关。未知请求字段通常先看流量与写入点；已知函数但结果不一致先做样本对拍；SDK 只能在浏览器运行时才考虑补环境。

路线结论必须包含：目标、已知事实、方案对比、推荐路线、待验证假设、下一步区分性实验。只给观点而没有实验不算路线结论。

## 3. 实施计划

计划以证据链为中心。每一步只做一件可在短时间内验收的事，并写清：动作、输入、产物、验证、失败回退、所需专业 Skill。

最小结构：

```markdown
# <目标> 实施计划

## 成功标准与判官
## 已知事实
## 待验证假设
## 交付物

### 任务 N：<单一目标>
- 输入：
- 动作：
- 产物：
- 验证：
- 失败回退：
```

避免“还原整个算法”“把环境补齐”“如果不对继续调”等不可验收步骤。计划涉及生产实现或实质性外部动作时，得到用户确认后才执行。

## 4. 按计划执行

执行前确认计划、样本、产物目录、成功标准和前置依赖均可用。每个任务固定循环：

1. 执行动作；
2. 保存原始产物；
3. 运行本步验证；
4. 记录本步支持或推翻了什么；
5. 验证通过后才进入下一步。

证据至少保留 HAR、原始请求、Hook 日志、调用栈、环境差异、样本对照或字节 diff 之一。允许因缺输入、Hook 点错误或假设被推翻而改计划，但必须说明证据并重新确认；禁止静默换路线。

## 5. 样本驱动复现

先准备至少 2 组探索样本，并明确动态字段与对比口径；完成声明使用至少 3 组非样例输入。

1. **RED**：先写会失败的真实 input→output parity 校验。
2. **GREEN**：只实现当前已证实的字段拼接、序列化和算法。
3. **REFINE**：按输入上下文→中间串→编码→最终结果逐层对齐。
4. **REFACTOR**：稳定后再拆为 `build_context()`、`serialize()`、`sign()`/`encrypt()`。

测试必须比较真实值或关键中间态；只断言某函数被调用不构成复现证据。无法固定的随机数、时间戳、会话 key 必须抽离或记录其生成与绑定。

## 6. 证据链排错

遵循 Observe → Hypothesize → Test → Fix：

- **Observe**：记录失败步骤、真实值、当前值和差异层级。
- **Hypothesize**：写出一个可被单变量实验推翻的原因。
- **Test**：一次只改一个时间、随机、字段、环境属性或 Hook 点。
- **Fix**：假设成立后再修复，并重跑原样本与新样本。

优先排查顺序：输入 → 动态字段 → 中间串 → 编码 → 算法参数 → 环境 → 调用点。

| 根因 | 转交 |
|---|---|
| Key/IV/Mode/Padding/拼接 | `param-encryptor` |
| 浏览器 API 或指纹行为不一致 | `env-patcher` |
| 混淆结构未还原 | `ast-deobfuscation` |
| 验证码坐标、轨迹或提交参数 | `captcha-solver` |
| 已知错误码或历史模式 | `web-reverse-field-guide` |

连续 3 次修改没有明确假设、同时改多个变量、证据未整理或已无法说明结果来自哪版代码时，立即停止并重建差异表。

## 7. 阶段出口

每轮只允许产出两类结果：

- 带文件、请求、日志、字节或业务响应锚点的结论；
- 能区分剩余假设的下一项实验。

未解析字段、oracle 依赖、重放值和时效炸弹必须显式记录，不能包装成纯算完成。
